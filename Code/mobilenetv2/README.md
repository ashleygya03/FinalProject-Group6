# MobileNetV2 ASL Classification

This folder contains the MobileNetV2-based American Sign Language (ASL) classification project

## Main files
- `main_mobilenetv2.py` — main training and evaluation script
- `src/` — source code for config, dataset, model, and utilities
- `tests/` — test files
- `requirements.txt` — required packages

## Run the project

Open terminal in this `mobilenetv2` folder and run to get model and outputs:

```bash
python main_mobilenetv2.py
