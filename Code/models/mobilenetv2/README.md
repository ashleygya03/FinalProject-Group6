# MobileNetV2 ASL Classification

This folder contains the MobileNetV2-based American Sign Language (ASL) classification project

## Main files
- `main_mobilenetv2.py` — main training and evaluation script
- `requirements.txt` — required packages

## Run the project

Open terminal in this `mobilenetv2` folder and run to get model and outputs:

```bash
python3 -m Code.models.mobilenetv2.main

```
## Download the trained model

- [Model](https://drive.google.com/file/d/1XS6T9E1l-4LDbOpx_vQQmSwPpCUsSE2t/view?usp=drive_link)

Or download it from terminal inside the `demo` folder:

```bash
wget --no-check-certificate "https://drive.google.com/uc?export=download&id=1XS6T9E1l-4LDbOpx_vQQmSwPpCUsSE2t" -O best_asl_model.keras
```
